# E2_TARGETS.md - where the engine's games differ from the record, written before code (2026-10-26)
E2a is a read (PRINTED): it locates the gaps; it assigns no cause from counts. E2b (later, its own targets) restores the engine's unplayed branches one family at a time. E1b (each unit's rates) waits until the engine's shared mechanics are fixed, so team rates never cover for an engine fault.

## 0. Same populations, same code
The engine's games (out/sim_games.csv) and the record's games for 2019-2021 and 2023-2025 (2022 out of everything) are counted by the same code (r1, r2 and r4's counts and one shared counting function), regular season and postseason apart, overtime apart. Every gap is printed per season with its range at 2SE, taken by game (games are the unit; snaps inside a game are not independent).

## 1. Possessions (engine 19.1 against the record's 21.7 a game)
Per game: possessions; each possession's length in snaps and in game seconds; how each ends (touchdown, field goal try, punt, turnover, turnover on downs, end of half, safety), as a rate per possession. Possessions per game = game seconds available / game seconds per possession, plus end-of-half pieces, printed side by side.

## 2. Plays (engine 120.8 against 137.5)
Plays = possessions x snaps per possession, both sides. Game seconds per snap by clock class: each class's share of stretches (RUN, STOP, PARTIAL) times its game seconds, by time bin (normal, last 2:00 of a half, last 5:00 of the game, overtime). No-plays and their share printed apart.

## 3. Points (engine 32.0 against 46.1)
Scoring chances (possessions reaching the opponent's 40; reaching its 20) per possession, times conversion (touchdown, field goal made), plus scores off the offense (returns, defensive touchdowns, safeties) and tries. Upper bound from the branches v0 does not play (E1_TARGETS section 3): the record's points on plays in each omitted family, per game, printed beside the 14.1-point gap.

## 4. Predictions (written before any number)
P-a. The points gap is mostly fewer scoring chances per possession and lower conversion; the omitted branches' upper bound is under 4 points a game.
P-b. The plays gap is mostly clock: the engine spends more game seconds per snap, shown as a larger running-clock share or longer running-clock stretches.
P-c. The possessions gap follows from P-b (more seconds per snap, so fewer possessions fit), not from how possessions end.
Each prints held or not held; a prediction that misses is read on its parts, never reworded.

## 5. Not done in E2a
No change to the engine; no team-specific rate; no cause named. The reads end with a list of candidate engine faults, one line each, naming the component (section 1, 2 or 3) and its size, for E2b's targets.
