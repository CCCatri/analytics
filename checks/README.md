# checks/ — every check the repository makes, and what each proves

- `test_transition.py`, `test_clock_check.py` — the product's own unit checks (each names, before it runs, the output that fails it).
- `test_incident_baseline.py` — `run.sh` stage 3: revision 12 reports no failures; revision 16's regression test refuses the injected predecessor and its two known failures appear exactly; its estimator oracle's measured under-coverage is printed, not judged.
- `check_generated.py`, `inject_generated.py`, `test_quality_gate1_injected_faults.py` — quality gate 1: generated games against the play-by-play record checks, and four injected violations each caught on the line named before the run.
- `reconcile_root_counts_by_position.py` — the attempt/carry reconciliation (3,200 of 3,200).
- `check_who_starts.py` — the who-starts law (P(starts) for quarterbacks, on the card beside P(plays)): walk-forward, it must name the starter better than P(plays) in every judged season; shuffled inputs must not.
- `check_one_game_one_reality.py` — one game, one reality: two quarterback lines on one team that each claim more than half of the team's attempts cannot be the same game, so they must carry different world labels (CI, reported; its self-test blocks).
- `check_possession_ends.py` — the possession-ends quality gate (law clause 4): every stop-and-score cell per game, record beside engine, 2SE, its false-alarm rate measured over 200 halvings of the record; exit 0 only when every cell is met (run.sh stage 5, reported; it gates the engine's scores as forecasts, not the run).
- `check_possessions_crosswalk.py` — our possessions against nflfastR's drives: every drive holds one possession or is a named kind (no snap, two-point try only, two pinned nflfastR numbering errors); three planted faults must be seen first (run.sh stage 4).
- `run_handoff.sh` → `test_handoff_baseline.py`, `test_handoff_adapter.py`, `test_handoff_replay.py`, `test_handoff_final.py`, with `handoff_identity.py` — the adapter harness: a baseline from the saved pre-adapter code, A1/B/B2/C, the isolated paired replay, one verdict per run id.
- `demo_w15.py` — the portable demonstration from a clean checkout (`fixtures/demo_w15/`, origins and pins beside it); `fixtures/regression_cases.csv` serves the unit checks.
- `check_targets_partition.py` — do receiver target draws and quarterback attempt draws fit inside the team attempts draw they were drawn from, game by game; three declared verdicts (supported / refuted / unknown); FAIL until the kit draws group slices jointly; `--self-test` proves it on a conserved slate, a injected independent slate and a missing parent.
